# Srishanth — Cybersecurity Portfolio

A responsive dark/neon-blue portfolio built with plain HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser. For a local server, use VS Code Live Server.

## Customize before publishing
- Update the GitHub profile links (currently generic `https://github.com/`).
- Replace sample project descriptions and GitHub links with your real projects.
- Confirm college/school details and add dates/certifications.
- Optionally add your own profile photo.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `srishanth143.github.io` (replace with your exact GitHub username if different).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes. Your site should appear at `https://YOUR-USERNAME.github.io/`.

If you use a repository with another name, the URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

This site is static and does not require a backend or build step.
